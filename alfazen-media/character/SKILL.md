# Character Design & Visual Consistency

Workflows and specifications for defining, maintaining, and rendering consistent characters, avatars, and personas across multiple generative scenes and media formats.

## Core Capabilities

1. **Character Model Sheets**: Defining canonical character traits (features, clothing, color palette, distinctive anchors).
2. **Multi-Angle & Expression Consistency**: Generating consistent front, 3/4, side, action poses, and facial expressions.
3. **Prompt Anchoring & LoRA Integration**: Crafting prompt templates and parameter weights to prevent character drift across media cuts.
